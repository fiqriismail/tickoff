# Tickoff website

Astro + Starlight generate the user-facing static HTML website. Developer app
build instructions and architecture remain in the [repository README](../README.md).

## Requirements and commands

Use Node.js 24 LTS (at least Node.js 22.23.4) and npm 9.6.5 or later.
Run these commands from this directory:

```sh
npm ci
npm run dev
```

Open <http://localhost:4321/tickoff/>. To validate a production build:

```sh
npm run check
npm run build
npm run preview
```

Preview also serves <http://localhost:4321/tickoff/>. Search is generated by
Pagefind during the production build, so test search in preview rather than
the development server. Stop either server with Control-C.

The static output is `dist/`. GitHub Pages deployment is tracked separately
in [#60](https://github.com/fiqriismail/tickoff/issues/60); this foundation does
not publish the site.

## Editing

- Add user guides as Markdown or MDX in `src/content/docs/`. Each page needs
  `title` and `description` frontmatter.
- Maintain Guide and Help navigation in `astro.config.mjs`.
- Use `src/styles/custom.css` for shared typography and colour tokens.
- `src/pages/404.astro` owns the error page; Starlight's injected 404 route is
  disabled to avoid generating a second route for the same address.
- Place processed content images in `src/assets/` and static files in `public/`.
- Keep internal Markdown links relative to the current page URL. In Astro
  components, construct local links and public asset URLs with
  `import.meta.env.BASE_URL`, which includes the `/tickoff/` prefix. Do not use
  domain-root links such as `/guide/`.
- Keep `package-lock.json` committed. Use `npm ci` for reproducible installs.

When adding, changing or removing a user-facing app feature, update affected
guides, landing-page descriptions, shortcuts and screenshots in the same change,
as required by [AGENTS.md](../AGENTS.md). Use only isolated fictional data in
screenshots.

Before submitting changes, run the check and build commands, then verify links,
search, keyboard navigation and mobile/desktop layouts in both light and dark
mode using production preview.
