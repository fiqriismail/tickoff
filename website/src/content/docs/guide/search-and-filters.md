## Choose a project scope

Select **All Projects** to see tasks across Tasks projects, or select a Tasks
project to narrow the list. Archived projects' tasks remain visible under All
Projects even though the projects no longer appear in the sidebar.

Daily Goals have their own Today view; they do not appear in task search results.

## Filter by status

In the sidebar's **Library** section, choose **All Tasks**, **To Do**,
**In Progress** or **Done**. These filters apply within the chosen project scope.
Selecting All Tasks does not switch the scope to All Projects.

Sidebar counts reflect the selected scope and status, not the current search.
The toolbar's completed/total summary also reflects the scope, not just the
visible search results.

## Search titles and notes

1. Choose a Tasks project or All Projects.
2. Press **Command-F** (**View > Find Tasks**) or use the toolbar search field.
3. Type part of a task title or note.

Search ignores letter case and spaces at the beginning or end of your query.
It matches the query as a contiguous phrase in the title or notes; project names
are not searched. Full notes are searched even when note previews are hidden.

Search, status and project scope work together. If a task seems missing, clear
the search, select All Tasks, then select All Projects.

:::caution[Search does not limit Clear Completed]
**Clear Completed** uses the project scope, not the search results.
Read [clearing completed tasks](../tasks/#clear-completed-tasks) before confirming.
:::
