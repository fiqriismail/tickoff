---

On a Mac keyboard, **Command** is ⌘, **Shift** is ⇧ and **Control** is ⌃.
Delete means the backward-delete key (⌫).

| Action | Shortcut | Availability |
| --- | --- | --- |
| Focus New Task | Command-N | Tasks view |
| New Project | Shift-Command-N | Any project view |
| New Goal | Shift-Command-G | Daily Goals project |
| Find Tasks | Command-F | Tasks view |
| Edit Task | Command-E | A visible task is selected |
| Delete task | Command-Delete | A visible task is selected |
| Delete task from the list | Delete | A task is selected and the list has keyboard focus |
| Hide or show sidebar | Control-Command-S | Main window |
| Quit Tickoff | Command-Q | Standard app command |

## In a task list

Select a task and press **Return** to edit it. Double-clicking does the same.
Control-click a row for **Edit**, **Change Status** and **Delete**.

:::danger[Task deletion has no confirmation]
Command-Delete and the list's Delete command permanently delete the selected task. There is no app-level undo
or Trash for task deletion. See [Tasks](../tasks/#delete-a-task).
:::

## In a field or editor

- In quick-add, **Return** adds the task.
- In the task editor's title field, **Return** saves; **Escape** cancels the sheet.
- In a goal editor's name or target field, **Return** submits; **Escape** cancels.

## Commands without a dedicated shortcut

Use **Task > Mark As** for an explicit status. Select a goal and use the **Goal**
menu for **Edit Goal**, **Toggle Completion** or **Increase Progress**,
**Decrease Progress**, and **Remove Goal**.

**Clear Completed** is in the File menu and toolbar More menu.
**Show Notes** and **Use Compact Rows** are in the View menu and toolbar More menu.
Commands that do not apply to the current view or selection are disabled.

The documentation website has its own search shortcut (**Command-K**); this is
not a Tickoff app shortcut.
