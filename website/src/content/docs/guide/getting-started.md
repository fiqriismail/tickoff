## Install Tickoff

1. Download the macOS universal ZIP from the
   [latest GitHub release](https://github.com/fiqriismail/tickoff/releases/latest).
2. Unzip the download.
3. Drag **Tickoff.app** into **Applications**.
4. Open Tickoff from Applications.

The same download supports Apple Silicon and Intel Macs running macOS 14 Sonoma
or later.

:::note[First-launch approval]
Tickoff is ad-hoc signed, not signed with an Apple Developer ID or notarised.
macOS may block the first launch. Follow the
[first-launch troubleshooting steps](../../help/troubleshooting/#macos-blocks-the-first-launch)
if this happens.
:::

## Add your first task

1. Select **Inbox** in the sidebar.
2. Enter a task title in the quick-add field and press **Return**.
3. Double-click the task to edit its notes, status, priority or due date.

Use the sidebar status filters to focus the list, or press **Command-F** to search
task titles and notes.

## Explore projects and daily goals

Choose **File > New Project** to create a project. Pick **Tasks** for ordinary
tasks or **Daily Goals** for daily check-offs and counters. A project's type
cannot be changed after creation.

Inside a Daily Goals project, use **New Goal** to add a check-off or a counter
with a positive whole-number target. Daily goals are separate from task searches
and task status filters.
