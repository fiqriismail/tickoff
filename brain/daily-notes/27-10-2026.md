- Worth knowing: `.dynamicTypeSize` does nothing on macOS, so text size is an explicit font scale (0.9 / 1.0 / 1.15, the Rust zoom factors) set as the root font. Views that set their own fixed text styles (`.caption` etc.) and native segmented controls don't follow it; later features should size text from the environment font (`.bold()`, `.font(.body)`-style relative tweaks) or add a scaled-font helper.

Manual runs can be redirected with `CFFIXED_USER_HOME` (not `HOME`).
- `fatalError` only exists for an in-memory SQLite open failing, which means SQLite itself is unusable.
- Follow-up: added a `system` accent (new default) that follows the macOS accent colour live (`NSColor.controlAccentColor`); the five fixed colours stay as overrides and saved choices are unchanged. Dark mode already defaulted to System. Text size stays an app setting by the user's choice (macOS has no system text size to inherit). 43 tests pass.
